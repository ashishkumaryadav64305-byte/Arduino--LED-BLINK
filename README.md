# Arduino LED Blink

## Overview
This is my first Arduino project. The objective is to understand how to control an LED using an Arduino Uno.

## Components Required
- Arduino Uno
- 1 LED
- 220Ω Resistor
- Breadboard
- Jumper Wires

## Circuit Connection
Arduino Pin 13 → 220Ω Resistor → LED (+)
LED (-) → GND

## Code
The Arduino turns the LED ON for one second and OFF for one second continuously.

## What I Learned
- Arduino Uno basics
- Digital Output Pins
- HIGH and LOW logic
- pinMode()
- digitalWrite()
- delay()
- Importance of a current-limiting resistor
